# Native stress baseline

These measurements were collected on November 11, 2026, before the compact-table parser was added, with the worktree built as an arm64 performance binary (`-tags=performance,mygo_noinspector -trimpath -ldflags=-s -w`). The host reported an Apple M1 Pro, 32 GiB RAM and macOS 27.2. The requested window was 2560 × 1312, but MyGo reported an effective 1280 × 820 content area. Each case used a fresh process and was settled for two seconds before one second of RSS sampling. The parser-only post-change measurements are in [`parser-baseline-2026-11-11.md`](parser-baseline-2026-11-11.md); a new real-window run is pending because the sandbox blocks the benchmark's `sysctl` metadata query.

| Fixture | Open action (ms) | Open capture (ms) | Settled RSS (MiB) | Sampled peak RSS (MiB) |
| --- | ---: | ---: | ---: | ---: |
| `table-heavy-1m.md` | 416.6 | 433.4 | 433.0 | 433.8 |
| `table-long-cells-1m.md` | 110.7 | 248.2 | 404.8 | 404.8 |
| `target-shape-12x1m.md` | 419.2 | 564.1 | 438.4 | 438.5 |
| `memory-heavy-1m.md` | 254.7 | 295.4 | 392.0 | 400.4 |
| `structured-1m.md` | 423.8 | 459.3 | 506.8 | 506.8 |

RSS includes resident native and shared pages and is not the same as macOS physical footprint. These values are a comparison baseline for this machine, not a product limit. The table cases show why row count, column count and cell content must be measured separately: equal byte sizes can produce different parser and layout costs.
