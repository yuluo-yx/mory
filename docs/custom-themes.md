# 用户主题

## 功能范围

Mory 支持与 Typora 相近的 CSS 主题工作流。用户可以导入 CSS 文件，也可以选择或打开应用主题目录后直接管理文件。主题会同时作用于所见即所得编辑区、HTML、PDF、PNG 和 JPEG 导出结果。

内置主题仍保存在应用资源目录。用户主题默认保存在当前用户的应用数据目录，也可以在设置中改为任意有读写权限的目录；Windows 不再固定依赖系统盘路径。选择结果保存在本机设置中，应用重启后继续使用，应用更新不会覆盖用户主题。

## 安装主题

打开“偏好设置 > 用户主题”，然后选择一种方式：

- 点击“导入 CSS”，选择不超过 1 MB 的 CSS 文件。
- 点击“更改目录”，选择用户主题所在目录；已有 CSS 会立即进入主题列表。
- 点击“打开目录”，把 CSS 和关联资源复制到当前目录。
- 修改文件后点击“刷新”，重新加载主题列表和样式。

Mory 使用 CSS 文件名作为显示名称。应用会为文件生成稳定标识，并把选择结果保存在本机设置中。

## 编写主题

正文容器同时包含 `#write` 和 `.write` 选择器。以下主题可以直接用于编辑与导出：

```css
#write {
  max-width: 760px;
  color: #2f2d29;
  font-family: "Songti SC", serif;
}

#write h1,
#write h2 {
  color: #27495f;
}
```

CSS 可以通过相对 `url(...)` 引用字体和图片。把资源放在主题目录内。Mory 加载主题时会把资源转换为 Data URL，确保导出文件不依赖本机路径。单套主题内联资源总大小不能超过 5 MB。

本地 `@import` 不会递归展开。需要组合多个 CSS 文件时，应在导入前完成合并。远程字体和远程样式受桌面页面内容策略约束，不保证离线可用。

## 导出行为

导出对话框会列出全部用户主题。选择“使用当前主题”时，Mory 会内联编辑区当前使用的 CSS。选择其他主题时，Mory 会临时读取目标主题，但不会切换编辑区。

删除主题文件后点击“刷新”。如果当前选择的主题已经不存在，Mory 会回退到 Yuluo CSS。Markdown 文稿不需要迁移。

## 实现位置

- Electron 主题目录与导入逻辑：`Electron/themes.cjs`。
- macOS 原生主题目录与导入逻辑：`Sources/Mory/ThemeManager.swift`。
- 主题应用与导出逻辑：`Sources/Mory/Web/app.js`。
- 内置主题：`Sources/Mory/Web/themes/`。
