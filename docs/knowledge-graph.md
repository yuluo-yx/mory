# 工作区知识图谱

## 目标

知识图谱用于观察同一工作区内文稿之间的链接关系。它是 Markdown 内容的派生视图，不创建数据库，不修改文稿，也不参与远端同步冲突处理。

入口位于编辑区右下角浮动栏。该入口使用独立图标，与格式、源码和导出操作保持同一纵向排列。

## 数据模型

每篇文稿对应一个节点。文稿之间的有效链接对应一条有向边。假设文稿 A 链接到文稿 B，A 的正向链接中会出现 B，B 的反向链接中会自动出现 A；Mory 不会为了建立反向链接而改写 B 的 Markdown。

Mory 识别以下链接：

- 双向链接：`[[目标]]`。
- 带显示名称的双向链接：`[[目录/目标|显示名称]]`。
- 带标题锚点的双向链接：`[[目标#章节]]`。
- 指向工作区文稿的相对 Markdown 链接：`[说明](../说明.md)`。

解析器会忽略代码围栏、行内代码、图片、网页地址和页内锚点。链接可以使用相对路径，也可以省略 Markdown 扩展名。短名称匹配到多个同名文件时，Mory 不建立边，避免错误连接。

节点标题优先使用文稿中的第一个一级标题。文稿没有一级标题时，节点使用文件名。

## 数据流

```text
当前工作区目录
    │ 读取不超过 2 MB 的 Markdown 文稿
    ▼
Electron / Swift 宿主
    │ 文稿名称、路径和内容
    ▼
Web 编辑器
    │ 合并已打开文稿的未保存内容
    ▼
链接解析与消歧
    │ 节点和有向边
    ▼
D3 力导向图
```

图谱每次打开或点击“刷新”时重新生成。已打开且尚未保存的文稿会覆盖磁盘中的旧内容，因此链接变化会即时进入图谱和反向链接列表。尚未保存到工作区的无路径草稿不会生成节点，也不会显示反向链接。

## 交互

- 拖动节点可调整局部布局。
- 使用滚轮或触控板缩放图谱。
- 输入文稿名称可突出匹配节点。
- 单击节点可查看“链接到”和“被链接”两个方向的关系；互相引用使用独立颜色和虚线表达。
- 双击节点或在聚焦节点后按空格键，可打开对应文稿。
- 当前文稿使用实心强调色节点。

当前文稿的反向链接还会出现在两个位置：

- 状态栏显示反向链接数量，点击后定位到文稿底部。
- 文稿底部列出所有引用来源，点击来源可打开对应文稿。

界面语言切换为英文后，知识图谱、方向标签、状态栏计数和文稿底部反链区会同步切换。

孤立文稿仍会显示。这样可以发现尚未建立链接的内容。

## 性能边界

宿主会跳过超过 2 MB 的单个文稿。图谱只读取 Markdown 和文本文件，不读取图片目录。D3 只在图谱面板打开时运行布局计算；关闭面板或切换工作区后，布局模拟会停止。

## 实现位置

- 文稿读取：`Electron/workspaces.cjs`、`Sources/Mory/WorkspaceManager.swift`。
- 链接解析与图模型：`Sources/Mory/Web/knowledge.js`。
- 图谱交互：`Sources/Mory/Web/app.js`。
- 图谱样式：`Sources/Mory/Web/styles.css`。
