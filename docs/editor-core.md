# Markdown 编辑内核行为说明

## 目标

编辑器以 Markdown 文本为持久化真相，以块级 DOM 作为当前编辑状态。标题、正文和代码围栏必须保持独立边界；输入法候选确认、普通换段和代码块退出不能共用同一条无条件回车逻辑。

最后验证日期：2026-08-15。

## 标题与中文输入法

- `# `～`###### ` 在块首转换为对应标题。
- 输入法组合期间不执行 Markdown 块替换，也不把带有 `isComposing` 或 `keyCode 229` 的 Enter 当成换段。
- 编辑器不使用可能滞留的全局组合输入锁。每个输入事件根据自身状态决定是否转换。
- `compositionstart` 会记录标题节点、文本插入点和相邻块。macOS WKWebView 在提交中文候选词时会先发送不可取消的 `deleteCompositionText`，并删除空标题节点；编辑器在对应 `input` 阶段把标题恢复到原位置，再让 `insertFromComposition` 在标题内提交候选词。
- `compositionend` 记录本次提交块。提交后 900 ms 内立即按 Enter 时，编辑器同步转换原始标题并创建正文块。
- 下一帧规范化会检查提交块是否仍存在。若 WebKit 把光标移到块首，编辑器先恢复到块尾再转换标题。
- 标题末尾的普通 Enter 创建新的正文块；连续标题不会合并。

第一次缺陷来自未区分组合输入。后续实现增加了全局组合输入锁，但该锁在部分 WebKit 时序中可能无法可靠释放。锁一旦滞留，后续标题快捷处理会全部失效。真实简体拼音事件追踪进一步确认，WebKit 会在候选提交时拆除空标题节点。当前实现删除了全局锁，恢复被拆除的语义节点，并为“提交后立即回车”提供同步块转换。

## 围栏代码块

输入 <code>```go</code> 后按 Enter 创建语言为 `go` 的代码块。以下操作只在光标位于代码块末尾时触发：

| 输入 | 状态变化 |
| --- | --- |
| 第一次 Enter | 插入代码换行，并进入 650 ms 的待退出状态 |
| 待退出期间输入文字 | 取消待退出状态，继续编辑代码 |
| 650 ms 内再次 Enter | 移除末尾空行，创建或复用后续正文并退出 |
| 方向下键 | 打开语言与名称字段，焦点进入语言字段 |
| 方向左/右键 | 在语言与名称字段间切换 |
| 元数据字段内方向下键 | 写回信息、关闭字段并退出到后续正文 |

仍可输入闭合围栏退出，兼容原有操作。

## 代码名称格式

代码名称采用围栏信息中的 `title` 属性：

````markdown
```go title="main.go"
fmt.Println("hello")
```
````

解析器同时接受属性式语言写法 ` ``` {.go title="main.go"}`。编辑器保存时统一输出前一种紧凑格式。名称存放在 `data-title`，编辑区和导出页面使用相同属性显示，因此 HTML、PDF、PNG 和 JPEG 保持一致。

## 代码高亮

Mory 使用 Highlight.js 11.11.1 的官方预构建浏览器资源。构建脚本把运行时和 BSD-3-Clause 许可证复制到 `Sources/Mory/Web/vendor/`，应用运行时不访问 CDN。

- 已声明围栏语言时，编辑器使用对应语言解析器。
- 未声明语言时，编辑器使用自动检测。
- 声明未知语言时，编辑器按纯文本显示，避免错误着色。
- 进入已高亮代码块时，编辑器保留文本和光标偏移，移除高亮 `span`；退出代码块后重新高亮。
- HTML 导出写入高亮后的 token DOM 和主题颜色。PDF、PNG 和 JPEG 使用同一份 HTML，因此结果一致。

## 默认主题

Yuluo CSS 是默认文档主题。主题依据本机 Typora 主题目录中的 `yuluo-css.css` 迁移正文排版、标题颜色、表格配色和代码样式。迁移实现不包含 Typora 专属选择器、远程字体请求或来源不明的字体文件，并为 Windows 增加系统字体回退。

旧版本仅使用默认 GitHub 主题且没有主题版本标记时，首次启动会迁移到 Yuluo CSS。用户后续主动选择的主题会保留。

## 验证矩阵

- 单元测试：围栏信息解析、名称转义、DOM 到 Markdown 往返。
- Electron 交互：组合输入回车、`compositionend` 后零等待 Enter、两个连续标题、双回车退出、方向键打开/切换/退出元数据。
- macOS 原生键盘：通过 `NSEvent` 实际输入两个 `# 你好` 和两行 Go 代码；真实输入法测试先放置 `#`，再通过系统简体拼音和物理键码输入空格、`nihao`、候选确认与 Enter，检查最终 `<h1>`、后续 `<p>` 与正文光标。
- 导出：命名代码在 HTML 中保留 `data-title`，Go 关键字生成高亮 token，并实际生成 PNG 与 PDF。

## 回滚

若需回退本次编辑内核行为，撤销 `Sources/Mory/Web/app.js`、`markdown.js` 和 `styles.css` 中的组合输入、代码元数据与高亮改动，并同步撤销对应测试。若只需回退默认主题，将 `mory.documentTheme` 改回 `github`，并移除 `mory.documentThemeDefaultVersion`。已有 Markdown 文档无需迁移；`title="..."` 只是围栏附加信息，不支持该扩展的渲染器通常会忽略它。
